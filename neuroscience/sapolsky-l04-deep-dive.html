What is a gene?
›
DNA（脱氧核糖核酸）是双螺旋结构，由两条互补链组成。碱基配对规则：A-T（腺嘌呤-胸腺嘧啶），G-C（鸟嘌呤-胞嘧啶）。人类基因组约 30亿碱基对，约 20,000–25,000 个基因。
关键数字

人类与黑猩猩基因组相似度：98.7%。但行为差异巨大——差异不仅在基因序列，更在基因表达时间、地点和程度。Sapolsky的核心观点：基因决定论是谬误。

转录：DNA变成RNA
Transcription: DNA → mRNA
›
转录发生在细胞核内：RNA聚合酶（RNA polymerase）沿DNA模板链合成前体mRNA（pre-mRNA）。
RNA加工步骤

① 5'加帽（保护mRNA）
② 剪接（splicing）：去除内含子（intron），保留外显子（exon）
③ 3'多聚腺苷酸尾（polyA tail）
→ 成熟 mRNA 出核，进入细胞质

重要：RNA是单链，碱基U（尿嘧啶）替代了DNA中的T（胸腺嘧啶）。
RNA聚合酶内含子/外显子pre-mRNA加工
🔧
翻译：RNA变成蛋白质
Translation: mRNA → Protein
›
翻译在核糖体上进行：mRNA上每3个碱基（密码子/codon）编码一个氨基酸。tRNA携带对应氨基酸识别密码子，氨基酸依次连接形成多肽链，折叠成蛋白质。
遗传密码的特性

• 64种密码子编码仅20种氨基酸 → 简并性（多个密码子编同一氨基酸）
• 起始密码子：AUG（甲硫氨酸）
• 终止密码子：UAA / UAG / UGA
• 密码子表几乎所有生物通用——生命统一性的证明

突变与多态性
Mutations & Polymorphisms
›
DNA复制偶尔出错，或受到辐射/化学物质损伤，产生突变。突变不一定有害，是进化的原材料。
同义突变
密码子改变但氨基酸不变（简并性保护），蛋白质功能不受影响
错义突变
一个氨基酸被另一个替换，可能改变蛋白质功能（镰刀型贫血是典型例子）
无义突变
产生提前终止密码子，蛋白质截短，通常功能丧失
移码突变
插入或缺失1-2个碱基，读码框完全打乱，后续氨基酸序列全错
SNP 单核苷酸多态性

人群中常见的单碱基差异（>1%频率）。人类基因组约有 1000万个SNP，是行为遗传学GWAS研究的基础。

三个真实案例
🔴
镰刀型贫血：错义突变的代价与收益
›
血红蛋白β链第6位谷氨酸→缬氨酸，一个点突变。结果：红细胞变形为镰刀状，携氧能力下降，贫血。

进化悖论：此突变在撒哈拉以南非洲高频存在（杂合子）——因为携带一个突变基因（杂合子）对疟原虫有天然抵抗力！杂合子适应度最高 = 平衡选择。这是自然选择、适应度和分子遗传的完美案例。
🧠
5-HTTLPR：血清素转运体基因变异
›
血清素转运体基因（SLC6A4）的启动子区有"短/长"多态性（5-HTTLPR）。短等位基因 → 转运体表达减少 → 突触血清素浓度升高。

Caspi等(2003)：携带短等位基因且有童年创伤者，抑郁症风险显著升高。但没有童年创伤？无差异。基因×环境交互的经典证据——基因不决定命运，环境激活基因潜力。
🌿
表观遗传：老鼠妈妈的舔舐改变基因表达
›
Meaney等研究发现：出生后被妈妈多舔舐/梳理的小鼠，长大后应激反应更平静，海马糖皮质激素受体更多。

机制：母亲关爱行为 → 减少海马GR基因启动子甲基化 → 基因表达增加 → 压力轴更受调控。DNA序列没有改变，但基因表达改变了，且可遗传给下一代。这就是表观遗传学的力量。
术语表 · Glossary
Transcription / 转录
以DNA为模板合成RNA的过程，发生在细胞核内，由RNA聚合酶催化
Translation / 翻译
以mRNA为模板在核糖体上合成蛋白质的过程，密码子对应特定氨基酸
Codon / 密码子
mRNA上编码一个氨基酸的三碱基序列，共64种密码子编码20种氨基酸
Exon / Intron — 外显子/内含子
外显子：编码蛋白质的序列；内含子：转录后被剪切掉的非编码序列
Point Mutation / 点突变
单个碱基对的改变，包括同义、错义、无义三类，对蛋白质影响不同
SNP / 单核苷酸多态性
人群中频率>1%的单碱基变异，GWAS研究的分子标记
Epigenetics / 表观遗传学
不改变DNA序列但影响基因表达的可遗传变化，如DNA甲基化、组蛋白修饰
Central Dogma / 中心法则
Francis Crick提出：信息从DNA→RNA→蛋白质单向流动（逆转录病毒是例外）
