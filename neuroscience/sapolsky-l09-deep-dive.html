🧩 核心概念速览 ▶

动物行为学 (Ethology) 是什么？

在自然环境中研究动物行为的学科，强调行为的进化功能和适应意义。代表人物：Konrad Lorenz、Niko Tinbergen、Karl von Frisch（1973年诺贝尔奖）。

固定行为模式 (Fixed Action Pattern, FAP)

由特定刺激（释放物/超常刺激）触发的、刻板、不可中断的行为序列。一旦启动就会完整执行，即使刺激已移除。

印记 (Imprinting)

在特定关键期内，某种经历对行为产生长期、相对不可逆的影响。最著名的是Lorenz 的灰雁印记：孵化后第一个移动物体 = 母亲。

关键期 vs 敏感期

关键期：某种学习必须发生的时间窗口，之后几乎无法再习得（如雁的母亲印记）。敏感期：更宽泛的影响窗口，经历后更容易习得，但不是唯一机会（如人类语言学习）。

印记的特点

✓ 发生在特定关键期内（孵化后12-36小时）
✓ 快速习得（单次暴露即可）
✓ 长期稳定，难以逆转
✓ 影响后期择偶行为（雄雁长大后求偶对象与印记对象相似）
✗ 不必主动练习，无需强化

性印记 (Sexual Imprinting)：幼年接触的物种/个体影响成年后的择偶偏好。动物园中单独抚养的鸟类常对饲养员产生求偶行为，跨物种性印记。

人类语言关键期的证据

Genie 案例：1970年发现的语言剥夺儿童，被隔离至13岁。获救后即使强化训练，语法习得始终存在严重缺陷，而词汇习得相对较好，支持关键期假说（句法 vs 词汇有不同关键期）。

早期双语：7岁前学习第二语言可达到母语水平（两套语言共用同一神经网络）；7岁后学习第二语言则使用独立但相邻的神经区域，难以消除口音。
❓ Tinbergen 的四个问题 ▶
Tinbergen 认为对任何行为的完整解释必须回答四个层次的问题：
问题层次举例（攻击行为）
机制
Mechanism		 近因（如何发生） 杏仁核激活，睾酮升高，神经环路激活
发育
Ontogeny		 近因（如何发展） 早期激素暴露，社会化经历，关键期塑造
功能
Function		 远因（为何存在） 保卫领地/资源/配偶，提高繁殖成功率
进化
Evolution		 远因（如何演化） 祖先物种的攻击行为模式，自然选择历史
Sapolsky 的核心主张：L02-L25 整个课程就是在用 Tinbergen 框架系统分析人类行为——从基因到神经到激素到个人经历到文化，每个层面都是真实的解释，没有一个是"最终"答案。
📚 经典案例深析 ▶

案例1：布谷鸟寄生与雏鸟 FAP

布谷鸟幼雏比养父母的亲生蛋更大、嘴更红。宿主亲鸟的喂食 FAP 被超常刺激激活，甚至在幼雏把其他蛋推出巢后仍继续喂食。这说明 FAP 不需要认知评估——刺激触发行为，行为自动执行。

案例2：Lorenz 的"水力模型"

Lorenz 用水箱比喻行为动机：能量不断积累，越来越容易被释放物触发，剥夺越久阈值越低（"空枪射击"——无刺激也自发释放）。虽然该模型过于简化，但引入了行为动机的内在状态概念，影响深远。

案例3：人类早期依附与关键期

Bowlby 和 Ainsworth 的依附理论：婴儿需要在早期（0-3岁）与照料者建立安全依附。罗马尼亚孤儿院研究表明，严重早期剥夺导致长期认知、情绪、社交缺陷，即使后来被收养也难以完全逆转——依附关键期的人类证据。

🧪 理解测验 ▶

关于固定行为模式 (FAP)，以下哪项描述正确？

正确！FAP 是刻板的、不需学习的行为序列。一旦被适当的"释放物"（releaser）触发，即会自动完整运行。刺棘鱼对腹部红色产生攻击 FAP，即使移走模型，攻击动作序列也会继续完成。

鸟类歌声学习关键期结束后再接触物种典型歌声，该鸟会？

正确！Marler 的鸣禽研究表明，隔离的雀类如果在关键期内没有听到同种歌声，成年后无法唱出完整正常的歌声。关键期内接触模板歌声 → 记忆储存 → 关键期结束后对照模板学习发声。无模板 = 无法对照，习得极度受限。
💡 核心要点 & 考点 ▶
1. FAP：由特定释放物触发，刻板、不可中断，超常刺激比自然刺激更有效
2. 印记：关键期内快速习得，长期稳定，影响后期社会和性行为
3. 关键期 vs 敏感期：严格程度不同，语言是敏感期，母亲印记是关键期
4. Tinbergen 四个问题：机制、发育、功能、进化——每个都是合法的解释层次
5. 人类例子：语言、依附、Westermarck 效应都有关键期/敏感期性质
